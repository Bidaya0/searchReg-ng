# 智能搜索与讨论系统


现在需要迁移到langgraph

这是一个基于 autogen 框架的智能搜索与讨论系统，能够对用户提供的主题进行深入分析和搜索，并生成结构化的结果。

## 功能特点

- 多智能体协作：使用 autogen 框架实现多个智能体之间的协作
- 主题分析：自动分析用户输入的主题，提取关键词和子主题
- 智能搜索：使用 Searx 搜索引擎进行多源搜索
- 结果总结：对搜索结果进行结构化总结和归纳
- 本地存储：自动保存分析结果、搜索记录和日志

## 系统组件

1. **主题分析器（Topic Analyzer）**
   - 解析用户输入的主题
   - 提取核心关键词
   - 生成相关子主题
   - 评估搜索难度

2. **搜索执行器（Search Executor）**
   - 执行搜索请求
   - 管理搜索结果
   - 使用 Searx 搜索引擎
   - 支持多引擎搜索

3. **内容记录器（Content Recorder）**
   - 记录搜索结果
   - 生成结构化摘要
   - 对内容进行分类和标记
   - 评估内容完整性

4. **用户代理（User Proxy）**
   - 管理对话流程
   - 执行工具调用
   - 协调其他代理

## 安装要求

- Python 3.8+
- 本地文件系统
- 网络连接
- 大模型API服务（GLM-4-9B或DeepSeek-R1-Distill-Qwen-32B）

## 安装步骤

1. 克隆仓库：
```bash
git clone [repository_url]
cd [repository_name]
```

2. 安装依赖：
```bash
pip install -r requirements.txt
```

3. 配置环境变量：
创建 `.env` 文件并设置以下变量：
```
API_KEY=your_api_key
BASE_URL=your_base_url
MODEL=your_model_name
```

## 使用方法

### 命令行模式

```bash
python main.py --topic "要搜索的主题" --max_results 20
```

参数说明：
- `--topic`：要搜索的主题（必填）
- `--max_results`：最大结果数量（可选，默认20）

### 交互式模式

```bash
python main.py --interactive
```

在交互式模式下，程序会提示你输入要搜索的主题。

## 输出结果

程序会输出三个主要部分：
1. 主题分析结果：包含关键词提取和子主题生成
2. 搜索结果：包含搜索到的相关内容
3. 最终总结：对搜索结果的总结和归纳

## 数据存储

系统会自动在 `data` 目录下创建以下子目录：
- `cache/`：存储缓存文件
- `results/`：存储搜索结果
- `logs/`：存储日志文件

## 错误处理

系统包含基本的错误处理机制：
- 搜索失败重试（最多3次）
- 本地文件读写错误处理
- 异常捕获和报告
